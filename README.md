# Lažybų IS – GUI prototipas

Grafinės naudotojo sąsajos maketas pagal naudotojo sąsajos navigavimo planą.

## Kas už ką atsakingas
| Aplankas / failas | Atsakingas |
|---|---|
| `index.html`, `css/`, `js/` | bendri (keičia vienas susitartas narys) |
| `prisijungimas.html`, `registracija.html`, `statymai/` (išskyrus `statymu-sarasas.html`), `lesos/` | Lukas Bernotas |
| `statymai/statymu-sarasas.html`, `koeficientai/` | Andrius Segalovičius |
| `ivykiai/` | Meda Vitkauskaitė |
| `admin/` | Miglė Kavaliauskaitė |
| `sablonai/`, `ataskaitos/` | Milanas Rinkevičius |

## Taisyklės
- Redaguok tik savo failus. Nauji failai – be lietuviškų raidžių ir tarpų.
- Lango antraštė (`<h1>`) turi sutapti su navigavimo plano pavadinimu.
- Nuorodos tarp langų – santykinės (pvz. `../admin/kategoriju-sarasas.html`).
- Geltonas „Šio lango turinys dar kuriamas“ blokas – ištrinti, kai langas užpildytas.
