# Lažybų IS – GUI prototipas

Grafinės naudotojo sąsajos maketas pagal naudotojo sąsajos navigavimo planą.

## Struktūra
| Aplankas | Posistemis |
|---|---|
| `index.html`, `prisijungimas.html`, `registracija.html` | Pagrindinis langas, prisijungimas, registracija |
| `statymai/` | Statymų valdymas |
| `lesos/` | Lėšų valdymas |
| `ivykiai/` | Lažybų įvykių valdymas |
| `koeficientai/` | Koeficientų, rizikos ir rezultatų valdymas |
| `admin/` | Naudotojų ir sistemos administravimas |
| `sablonai/` | Standartizuoti statymo tipų šablonai |
| `ataskaitos/` | Ataskaitos ir statistika |
| `css/`, `js/` | Bendras dizainas ir funkcijos |

## Taisyklės
- Redaguok tik savo posistemio failus. Nauji failai – be lietuviškų raidžių ir tarpų.
- Lango antraštė (`<h1>`) turi sutapti su navigavimo plano pavadinimu.
- Nuorodos tarp langų – santykinės (pvz. `../admin/kategoriju-sarasas.html`).
- Geltonas „Šio lango turinys dar kuriamas“ blokas – ištrinti, kai langas užpildytas.
